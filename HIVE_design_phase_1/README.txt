DESIGN DIRECTION
- Visual language: dark glass / layered interface with soft blur, subtle borders, violet glow and restrained gold status accents.
- Primary: #7028F5
- Secondary: #A855F7
- Accent: #F5B942 (status/highlight use only)
- Background: #080817
- Surface: #17162B
- Border: #373052
- Text: #FFFFFF
- Muted: #A6A1BC
- Typography: Manrope for headings; Inter for body and interface text.
- Brand line: Learn Together. Grow Smarter.

IMPORTANT PRODUCT CONSTRAINTS FROM THE HIVE SPECIFICATION
- No subscriptions, payments, premium tiers, advertisements, or upgrade prompts.
- AI answers must be grounded in class materials and show citations/sources.
- Student, Representative/Moderator, and Administrator permissions must remain distinct.
- Mobile-first responsive PWA; timetable and previously downloaded revision sheets should remain available offline.
- Zero-cost operation: free tiers/open-source only; reaching a quota should queue/degrade gracefully, never trigger paid usage.

NEXT DESIGN/BUILD SEQUENCE
1. Finalize the logo as a clean scalable vector and app icon.
2. Produce individual high-fidelity screens, starting with authentication and Student Portal.
3. Produce Representative and Administrator screens.
4. Implement the approved screens as a responsive, navigable React/Next.js frontend.
5. Add realistic interactions and connect the UI to Supabase only after the screen flows are validated.

The PNGs are concept boards, not final editable Figma files or production vector assets. Text and details inside generated mockups should be treated as visual direction; implementation will use precise UI text and components.
